| santa | 圣诞猫 | 30 秒生成一次随机增益道具 | 8 个礼物炸弹，每个 3 倍；每秒 2% |

技能基础伤害为 `10 × 倍数 × 当前伤害倍率 × 全局伤害增益`，并继续经过通用敌人伤害处理。基础充能阈值受已有能量卡牌和被动加成影响；持续大招与扑击期间不再通过普通事件充能，能量电池仍可直接补能。内部能量为 0–1，HUD 显示百分比。

区域减速取最强值；Boss 最多减速 20%，新角色技能不强制移动或恐惧 Boss。泪水与水洼的伤害可独立生效。暂停期间战斗不推进，死亡和新开局清理技能、区域与延时任务。招财猫额外金币不会再次触发被动，也不计入金币充能。

所有角色 ID、价格、初始武器、基础属性加成与活动解锁条件保持不变。已有角色购买、选择及限定角色解锁记录无需迁移。旧角色美术源数据保留在仓库中，但新图集不再加载旧角色图集。

## 验证

```bash
npm run check
npm run build:web
npm run serve
# 另开终端：
npm run test:meme
# 自定义服务地址或 Chromium 路径：GAME_URL=... CHROME_BIN=... npm run test:meme
```

本轮使用 `http://localhost:8092/web/` 执行 Chromium 回归：123 项技能、图集与模拟战斗断言通过；真实鼠标选角、开始游戏、键盘移动、死亡结算／重开、暂停／恢复、旧存档持久化重载通过。无页面异常、控制台错误或缺失精灵警告。

## 角色形象第二版

第二版改进了猫咪的毛色、脸型、耳位与原梗姿态，Pepe 使用低垂眼皮和厚嘴唇。奶蛙与泡泡团团的最终形象以第三版为准。刀盾狗保持原样。

源图和复现说明见 `tools/art/README.md`。导入结果仍为 48×64、三帧动画，使用原同步像素图集；不增加运行时图片请求，也不改变技能、价格或存档格式。

第二版已通过类型检查、浏览器构建和原有 123 项回归断言，实际选角、移动、暂停恢复、死亡结算重开及存档重载通过。`validation/meme-roster.png`、`meme-selection.png`、`meme-fire.png` 和 `meme-bubbles.png` 已更新为第二版；`meme-roster-before.png` 保留第一版用于对照。


## 两名角色重新设计（第三版）

- `mage`：奶蛙，黄色梨形身体、绿眼圈、黑瞳、小嘴和小手脚的网红蛙形角色；被动“奶蛙吐息”，大招“奶蛙爆笑”。
- `knight`：泡泡团团，薄荷色机身、方形玻璃面罩、电子眼与泡泡罐的机器人形象；被动“泡泡护盾”，大招“泡泡净场”。
- 原有召唤物与飞弹改名为“奶泡精灵”“奶香飞弹”，主菜单台词同步更新。
- `naiwa-source.png` 覆盖 `mage`，`original-pair.png` 仅以右侧机器人覆盖 `knight`，左侧幼童槽位停用；其他九份角色源数据经逐项比较完全一致。
- 类型检查、官方 Cocos 3.8.8 类型检查、浏览器构建及原有 123 项回归断言通过；角色总览、选角和两个技能截图已更新。


## 名称纠正：奶蛙

按用户纠正，`mage` 指网红“奶蛙”。之前的幼童理解和对应源图已停用，当前采用黄色梨形身体、绿眼圈、短嘴、小手脚的蛙形形象。大招“奶蛙爆笑”、被动“奶蛙吐息”，保留原有能量吐息机制、角色 ID、购买与存档记录。泡泡团团及其他角色不变。
